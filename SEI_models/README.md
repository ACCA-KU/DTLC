# SEI Models

This notebook `contribution_analysis.ipynb` uses the trained **BLI-GAT-SEI**
model (`Trained_models/BLI_segment_sum_contribution`), and plots the contribution
distributions.

It reproduces **Figure 7** of the paper.


## Input file format
| File                 | Content                                                                 | Figure   |
|----------------------|-------------------------------------------------------------------------|----------|
| `data/molecules.csv` | 11,486 compounds in Hex/EA at 10:1, 4:1, 1:1 (v/v), given as mole fractions | Figure 7 |
